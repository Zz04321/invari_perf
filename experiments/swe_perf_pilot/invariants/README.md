# Invariant Context Files

Put one invariant JSON file here per real SWE-Perf task.

The file must use `../config/invariant_context.schema.json` and its `task_id`
must match the official SWE-Perf instance id in the task config.

This directory intentionally does not include a toy example. The pilot is meant
to run on real SWE-Perf instances only.
